# 百度搜索

参考，不是可执行步骤。

- 搜索框的 placeholder 经常是一条热搜标题，不是这个框的稳定名字。要输入的是目标里点名的查询词，例如目标写「搜索携程」就只输入「携程」。这个查询词只用于搜索框，不要填进后来的城市框或机场框。
- 输入后点「百度一下」。
- 名字像「官网」但链接标记是 `baidu.com/s` 的，是相关搜索，点了只是换一条百度搜索。不要点。
- 带「下载」「广告」「APP」的结果不要点。链接标记是 `e.baidu.com` 的是广告，标题即使像官网也不要点。
- 要打开官网时，点结果标题，而且链接标记是 `baidu.com/link` 的那条。点完地址应离开 baidu.com，落到目标站点，而不是 `e.baidu.com`。
- 标题下面的绿色小字网址（例如 `www.ctrip.com`）经常点不走，还停在百度。不要点这行小字。如果点过一次地址仍是 baidu.com，不要再点它。
- 不要把新闻标题当成搜索框。
